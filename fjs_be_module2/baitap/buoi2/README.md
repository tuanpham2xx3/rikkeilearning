# Buổi 2 - NestJS Providers & Modules

```bash
npm install
npm run start:dev
```

Các endpoint demo:

- `GET /info`: custom provider dùng `useValue`.
- `GET /modules`: module re-exporting và circular dependency.
- `GET /config`: dynamic module.
- `GET /startup`: async provider.

`bai6-monorepo/` là skeleton monorepo độc lập với `apps/api`, `apps/admin` và `libs/database`.
