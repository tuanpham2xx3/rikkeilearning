BÀI 3: QUẢN LÝ GIAO DỊCH (TRANSACTIONS & SAVEPOINTS)

Bối cảnh:

BÀI 5: TOKEN BLACKLISTING (ĐĂNG XUẤT THẬT SỰ)

Bối cảnh:
JWT là stateless. Xóa JWT ở frontend không làm token đó hết hạn trên server. Nếu bị trộm, hacker vẫn xài được.

Yêu cầu:

Viết API POST /auth/logout.
Khi gọi, lưu Access Token hiện tại vào một tập hợp "Blacklist" (Có thể dùng mảng in-memory, nâng cao dùng Redis).
Chỉnh sửa JwtStrategy kiểm tra nếu token nằm trong blacklist thì ném lỗi Unauthorized.
Kết quả mong đợi:
Chặn đứng tức thì những token đã "đăng xuất" dù chúng còn hạn.
Ghi chú: Chụp ảnh Postman gọi API sau khi logout bị 401.
