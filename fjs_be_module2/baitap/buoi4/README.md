# Buổi 4 - DTO, Validation và REST nâng cao

```bash
npm install
npm run start:dev
```

Routes: `POST /users`, `GET /products`, `POST /posts`, `POST /events`, `GET /products/:id`, `POST /users/:id/avatar`.

ValidationPipe được bật với `transform: true`, nên query `page=2&limit=10` được nhận dưới dạng number.
